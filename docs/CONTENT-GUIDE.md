# Управление контентом: инструкция редактора

Как публиковать статьи, работать с категориями, медиатекой и обращениями.
Всё, что описано здесь, делается через браузер, без доступа к серверу.

---

## 1. Вход в панель

Адрес: `вашдомен.ru/admin/login` (в подвале сайта есть ссылка «Вход для редактора»).

## 2. Статьи

### Создание
1. **Статьи → Создать статью.**
2. Введите заголовок — URL сгенерируется автоматически после ухода из поля
   (можно править вручную или нажать «Сгенерировать»). URL — латиницей, это
   важно для поисковых систем: `family/kak-podat-na-razvod/`.
3. Выберите категорию — обязательное поле.
4. Напишите текст в редакторе. Оглавление статьи построится само из заголовков
   H2 и H3 — используйте их для структуры (кнопки H2/H3/H4 на панели).
5. Заполните «Краткое вступление» — оно показывается в списках и берётся в
   description, если не задан SEO-текст.
6. Нажмите **Опубликовать** (или «Сохранить черновик», чтобы вернуться позже).

### Поля в правой колонке
- **Дата публикации** — проставляется сама; можно задать будущую дату вручную.
- **Дата последней проверки** — заполняйте, когда перечитали и сверили материал
  с действующими нормами; посетитель видит «Проверено: …» — это повышает доверие.
- **Тестовая публикация** — показывает на сайте красный баннер «Тестовая
  публикация». Используйте для черновых проверок вёрстки.
- **Обложка** — выбирается из медиатеки; попадает в Open Graph (картинка при
  репосте в соцсети и мессенджеры).
- **Видео** — вставьте ссылку YouTube/RuTube/VK/Дзен — на сайте появится плеер.
- **Автор** — имя показывается на странице статьи. Используйте реальные данные:
  если автор — редакция, так и напишите. Разметка Person добавляется только
  когда поле заполнено.
- **Нормативные акты** — выводятся блоком «Нормативная база» (например,
  «Семейный кодекс РФ, глава 13»).
- **Связанные статьи** — блок «Читайте также». Если не выбрать — покажутся
  свежие материалы той же категории.

### Редактирование и статусы
- **Опубликованная статья**: кнопки «Сохранить изменения», «Снять с публикации»,
  «Открыть на сайте», «Удалить».
- **При изменении URL** опубликованной статьи старый адрес автоматически
  начинает отдавать постоянный редирект (301) на новый — посетители и поисковые
  системы не увидят ошибку 404. Дополнительных действий не требуется.
- **Снятие с публикации** скрывает статью с сайта, но сохраняет текст и даты.
- В списке статей есть быстрый поиск, фильтры по статусу и категории, кнопка
  публикации/снятия в строке.

### Информационные блоки в тексте
- 💡 **Информационный блок** — советы и примечания.
- ⚠️ **Предупреждение** — важные оговорки (например, «сроки меняются»).
- ⚖️ **Нормативная база** — моноширинный блок для ссылок на законы.
- ❓ **Вопрос — ответ** — оформление FAQ; при наличии таких блоков на странице
  автоматически добавляется разметка FAQPage для поисковых систем. Добавляйте
  её только там, где вопросы и ответы действительно есть.
- **Таблицы** — на мобильных телефонах прокручиваются горизонтально.
- **Вставка из Word** — списки, таблицы и базовое форматирование переносятся;
  после вставки проверьте текст и при необходимости снимите лишнее
  форматирование кнопкой «Очистить форматирование».

## 3. Категории

- **Категории → Создать категорию**: название, URL, описание (показывается на
  странице раздела), SEO-заголовок и description.
- **Изображение категории** — выбирается из медиатеки. Показывается в карточке
  раздела в каталоге «Юридические вопросы» и как картинка Open Graph на
  странице раздела. Рекомендуемый формат: горизонтальный 3:2 (например,
  1344×768), спокойные тематические фотографии без текста. Если изображение
  не выбрано, карточка отображается с иконкой раздела.
- **Порядок отображения** — влияет на меню и главную страницу (кнопки ↑/↓).
- **Тематическая подборка** — флажок выводит раздел в блок «Тематические
  подборки» на главной (до трёх разделов).
- **Родительская категория** — позволяет вложить раздел (отображается в
  хлебных крошках). URL при этом остаются плоскими: `/{slug}/`.
- Удалить категорию можно, только если в ней нет статей.
- При изменении URL категории старый адрес автоматически редиректит на новый.

## 4. Медиатека

- **Медиатека → Загрузить изображения**: JPG, PNG, WebP, GIF, до 5 МБ на файл
  (лимит меняется переменной `MAX_UPLOAD_MB`). SVG не поддерживается из
  соображений безопасности.
- **Alt-текст** задавайте сразу при загрузке и позже (карандаш на карточке) —
  это важно и для доступности, и для поиска по картинкам.
- Копирование ссылки на файл — кнопка «копировать» на карточке.
- Удаление файла, который используется в статьях, требует подтверждения —
  иначе картинки в статьях сломаются.

## 5. Обращения посетителей

- **Обращения**: список с фильтром по статусу (новый / в работе / завершён).
- В карточке обращения — контакты, тема, текст и страница, с которой отправили.
- Кнопка «Ответить по e-mail» открывает письмо с адресом заявителя.
- **Экспорт CSV** — выгрузка всех обращений для Excel.
- Пока SMTP не настроен, письма не отправляются, но каждое обращение
  сохраняется здесь. Проверяйте раздел регулярно — на дашборде есть счётчик
  «Новые обращения» и напоминание, если e-mail не подключён.

## 6. Настройки сайта

- **Общие**: название (временное «Правовой гид» меняется здесь), описание,
  адрес сайта (после подключения домена), основной цвет (меняет акцент всего
  сайта), логотип, текст подвала, блок «О проекте».
- **Главный экран**: заголовок, подзаголовок и текст кнопки на главной.
- **Контакты**: телефон, e-mail, адрес, время работы; пустые поля не
  показываются на сайте. «E-mail для получения обращений» используется,
  когда подключен SMTP.
- **Соцсети**: добавляйте только реальные ссылки. Пока список пуст, кнопки
  соцсетей на сайте не показываются. Поддерживаются Telegram, ВКонтакте,
  YouTube, Дзен, Одноклассники, Rutube.
- **Юр. документы**: редактируемые Политика конфиденциальности, Согласие на
  обработку данных и Пользовательское соглашение. Шаблоны в комплекте
  помечены предупреждением «не проверен юристом» — после адаптации включите
  переключатель «Документ проверен».
- **SEO и аналитика**: title и description главной, номер счётчика Яндекс
  Метрики, Google Analytics, коды верификации Яндекс Вебмастера и Search
  Console. Скрипты подключаются сразу после сохранения.

## 7. Поиск по сайту

Поиск индексирует заголовки, вступления, тексты и теги опубликованных статей.
Страница `/search/` скрыта от поисковых систем (страницы результатов не должны
индексироваться) — это штатная практика.

## 8. Редиректы

Раздел «Редиректы» — для адресов со старого сайта (при переносе) и любых
своих перенаправлений: укажите старый путь, новый и код (301 — постоянный,
302 — временный). Редиректы при изменении URL статей и категорий создаются
автоматически и появляются в этом списке.
