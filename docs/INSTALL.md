# Юридический сайт для граждан России — установка и запуск

Полноценный сайт юридической помощи с собственной CMS: статьи, категории, медиатека,
формы обращений, SEO-инструменты. Стек: **Next.js 16 + SQLite (Prisma) + Tailwind**.

---

## 1. Требования

- **Node.js 20+** (или Bun 1.2+) — на сервере и на компьютере разработки
- 512 МБ оперативной памяти достаточно для старта (рекомендуется 1 ГБ)
- Диск: сайт занимает ~200 МБ с зависимостями; база данных и картинки растут по мере работы

## 2. Быстрый старт (локально)

```bash
# 1. Установить зависимости
npm install            # или: bun install

# 2. Создать файл .env в корне проекта:
cat > .env << 'EOF'
DATABASE_URL=file:/полный/путь/к/проекту/db/app.db
# NEXT_PUBLIC_ и секретные переменные не требуются
EOF

# 3. Применить схему базы данных
npx prisma db push     # или: bun run db:push

# 4. Создать администратора, категории и настройки
ADMIN_EMAIL="ваш@email.ru" ADMIN_PASSWORD="СложныйПароль123!" npx bun prisma/seed.ts
# (если seed выполняется через npm: npx tsx prisma/seed.ts — установите tsx: npm i -D tsx)

# 5. Запустить
npm run dev            # разработка: http://localhost:3000
npm run build && npm start   # продакшен: http://localhost:3000
```

**Важно:** пароль администратора задаётся ТОЛЬКО при первом запуске seed.
Если seed уже выполнялся с паролем по умолчанию — смените пароль после первого
входа (см. раздел «Администратор» ниже).

## 3. Переменные окружения (.env)

| Переменная | Обязательна | Описание |
|---|---|---|
| `DATABASE_URL` | да | Путь к файлу SQLite: `file:/путь/db/app.db` |
| `SITE_URL` | рекомендуется | Адрес сайта вида `https://вашдомен.ru` — для canonical и sitemap (можно задать и в админке) |
| `SITE_NAME` | нет | Название в теме писем |
| `MAX_UPLOAD_MB` | нет | Лимит размера загружаемых изображений (по умолчанию 5) |
| `UPLOAD_DIR` | нет | Каталог хранения загруженных изображений (по умолчанию `./uploads`) |
| `SMTP_HOST` | нет | SMTP-сервер для уведомлений о обращениях |
| `SMTP_PORT` | нет | Порт SMTP (465 — SSL, 587 — STARTTLS) |
| `SMTP_USER` | нет | Логин SMTP |
| `SMTP_PASSWORD` | нет | Пароль SMTP |
| `SMTP_FROM` | да, при SMTP | Адрес отправителя `Сайт <noreply@вашдомен.ru>` |
| `FEEDBACK_TO_EMAIL` | да, при SMTP | Адрес получателя обращений |

**Обращения работают без SMTP**: каждое обращение сохраняется в базу и видно
в админ-панели → «Обращения». E-mail-уведомление — дополнительная удобная
доставка, а не единственный канал. Пока SMTP не настроен, посетитель видит
честное сообщение об этом.

## 4. Администратор

- Страница входа: `/admin/login`
- Пароль хранится в виде scrypt-хеша — восстановить нельзя, можно только сбросить:

```bash
# Сброс пароля администратора (выполнить на сервере в каталоге проекта):
bun -e '
import { PrismaClient } from "@prisma/client"
import { scryptSync, randomBytes } from "crypto"
const db = new PrismaClient()
const email = "ваш@email.ru"
const password = "НовыйСложныйПароль!"
const salt = randomBytes(16).toString("hex")
const hash = scryptSync(password, salt, 64).toString("hex")
await db.adminUser.update({ where: { email }, data: { passwordHash: `scrypt$${salt}$${hash}` } })
console.log("Пароль обновлён для", email)
await db.$disconnect()
'
```

- Смена пароля «на ходу»: создайте нового администратора тем же seed-скриптом
  с другим email, войдите под ним и удалите старую учётную запись из базы
  (`db.adminUser.delete`), либо используйте скрипт выше.
- Все попытки входа журналируются; после 8 неудачных попыток IP блокируется на 15 минут.

## 5. Структура проекта

```
├── prisma/schema.prisma      # схема БД (статьи, категории, медиа, обращения…)
├── prisma/seed.ts            # сид: админ, 14 категорий, настройки, тестовые статьи
├── db/                       # файл базы данных SQLite
├── uploads/                  # загруженные изображения (год/месяц/файл)
├── docs/                     # эта документация
├── scripts/e2e-api-tests.sh  # автотесты API (42 проверки)
└── src/
    ├── app/(public)/         # публичные страницы: главная, категории, статьи,
    │                         # поиск, контакты, о проекте, юр. документы
    ├── app/admin/            # админ-панель (вход, дашборд, статьи, категории,
    │                         # медиа, обращения, редиректы, настройки)
    ├── app/api/              # API: авторизация, админ-CRUD, обратная связь
    ├── app/media/            # раздача загруженных изображений
    ├── app/sitemap.ts        # карта сайта
    ├── app/robots.txt        # robots
    └── lib/                  # ядро: auth, настройки, санитайзер, медиа, почта
```

## 6. Автотесты

```bash
bash scripts/e2e-api-tests.sh
```

Скрипт проверяет: защиту админ-API, вход, полный цикл статьи (черновик →
публикация → смена URL с автаредиректом → снятие → удаление), категории,
загрузку/отдачу/удаление медиа, отклонение SVG, форму обратной связи
(валидация, анти-спам, согласие), настройки, редиректы, sitemap, robots.

## 7. Что сделать перед запуском в интернете

1. Выполнить seed с собственным e-mail и паролем.
2. В админ-панели: Настройки → заменить название сайта, тексты главного экрана.
3. Настройки → Юр. документы: отредактировать политику, согласие и соглашение
   под свой проект (шаблоны помечены «не проверен юристом»), отметить проверку.
4. Удалить тестовые статьи (помечены баннером «Тестовая публикация»).
5. Заполнить контакты или оставить пустыми — пустые поля не показываются.
6. После подключения домена указать его в Настройках (поле «Адрес сайта»).
7. Подключить Яндекс Метрику и Вебмастера (Настройки → SEO и аналитика).
