# Юридический сайт для граждан России

Полноценный сайт юридической помощи с собственной CMS: статьи, категории,
медиатека, обращения, SEO-инструменты и административная панель.

- **Стек:** Next.js 16 (App Router) · TypeScript · SQLite + Prisma · Tailwind CSS 4 · shadcn/ui · TipTap
- **Стоимость эксплуатации:** VPS от ~200 ₽/мес + домен; всё остальное (СУБД, HTTPS, аналитика) — бесплатно
- **Почему не WordPress:** редиректы при смене URL, честные обращения, поля юридического контента («дата проверки», «нормативная база») и строгий контроль SEO в WordPress потребовали бы 6–8 плагинов с рисками безопасности; здесь это ядро системы. Сравнение подходов — в задании проекта, детали — в docs/.

## Возможности

**Публичная часть** (всё на русском, адаптивная, быстрая, дизайн — белый фон + глубокий тёмно-синий):
- главная: двухъярусная шапка (логотип, описание, соцсети + тёмно-синяя навигация с поиском), hero с иллюстрацией и поиском, карточки юридических категорий с иконками, «Популярные материалы», «Последние публикации», боковые блоки «Нужна юридическая помощь?» и «О проекте»;
- страницы категорий с сортировкой по дате и пагинацией; сводная страница «Статьи» (`/articles/`) и каталог «Юридические вопросы» (`/categories/`);
- статьи с авто-оглавлением, метадатами (публикация/обновление/проверка), нормативной базой, дизлеймером, кнопками «поделиться», блоком «Читайте также» и призывом обратиться за помощью;
- поиск, контакты с формой (анти-спам, серверная валидация, согласие на обработку данных), «О проекте», редактируемые юридические документы, страница 404;
- SEO: уникальные title/description, canonical, Open Graph, JSON-LD (Article, BreadcrumbList, WebSite, FAQPage — только при наличии реальных Q&A), sitemap.xml, robots.txt, redirects 301 при смене URL, подключение Яндекс Метрики/GA и кодов верификации.

**Админ-панель** (`/admin`):
- статьи: черновики, публикация/снятие, все SEO-поля, обложка, видео по ссылке, теги, автор, даты, связанные материалы, тестовая пометка;
- визуальный редактор: H2–H4, форматирование, списки, таблицы, ссылки, изображения из медиатеки, видео, цитаты, информационные блоки, «Вопрос — ответ», вставка из Word;
- категории: порядок, вложенность, признак «подборка», SEO-поля, авто-редирект при смене URL;
- медиатека: загрузка с проверкой форматов, alt/описание, удаление с защитой используемых файлов;
- обращения: статусы, детали, экспорт CSV;
- редиректы и полный набор настроек сайта (название, цвета, контакты, соцсети, юридические документы, аналитика).

**Безопасность:** scrypt-хеши паролей, сессии в БД, блокировка перебора входа, CSRF/Origin-защита, санитайзер HTML, проверка магических байт при загрузке, honeypot и лимиты для форм, защита админ-API на каждом обработчике.

## Быстрый старт

```bash
npm install
npx prisma db push
ADMIN_EMAIL="ваш@email.ru" ADMIN_PASSWORD="ВашПароль!" npx tsx prisma/seed.ts
npm run dev            # http://localhost:3000, админка: /admin/login
```

## Состояние из коробки

- В базе: 14 категорий юридической тематики, настройки, 4 **тестовые статьи**
  (помечены баннером «Тестовая публикация», удаляются в админке одной кнопкой).
- Названия проекта, контакты, соцсети — заполните в Настройках; фиктивные
  данные не добавлялись.
- Юридические документы — шаблоны с честной пометкой «не проверен юристом».
- Автотесты: `bash scripts/e2e-api-tests.sh` (42 проверки).
